Notification keys

One-time setup for the host. This page makes a fresh key pair in your browser. Nothing is sent anywhere.

1. Save the private key as a GitHub secret

Repo → Settings → Secrets and variables → Actions → New repository secret. Name it VAPID_PRIVATE_KEY and paste this value.

Keep this one private. Don't paste it in chats or commit it.

2. Run this in Supabase's SQL Editor

It stores the public key and a fingerprint of the private key (not the key itself).

That's it. Reminders start going out within the hour. If you reload this page you'll get a different pair, so do both steps with the same one.
